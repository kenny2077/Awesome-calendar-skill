Awesome Calendar Skill

The calendar above was generated by GPT in one shot, from nothing but syllabus files. Here is how to make yours.

Download the skill View on GitHub
  1. 1

    Get the file

    Download or copy SKILL.md. One Markdown file, nothing to install.

  2. 2

    Paste it in

    ChatGPT, Claude, Claude Code, Codex — whichever you already use.

  3. 3

    Add your syllabi

    PDFs, schedule pages, Canvas grade tables, screenshots, plain text. Mixed and messy is fine.

  4. 4

    Open the result

    Ask for the semester matrix, save the HTML it returns, open it in any browser.

The skill scores its own render and fixes it before handing it over, which is why the first output is usually the one you keep. Nothing is uploaded and nothing runs on a server — what comes back is a single HTML file that works offline.
