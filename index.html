Make one for your semester

The skill is a single Markdown file. It carries the layout rules, the symbol vocabulary, and a self-inspection loop that makes the model score its own render and fix it before handing it to you — which is why the first output is usually the one you keep.

  1. Press Copy the skill above, or open skills/semester-matrix/SKILL.md and copy the whole file.

  2. Paste it into ChatGPT, Claude, Claude Code, Codex — whichever you already use.

  3. Attach your course material: syllabus PDFs, schedule pages, Canvas grade tables, screenshots, plain text. Mixed formats are fine. Messy is fine.

  4. Ask for the semester matrix, then save the HTML it gives you and open it in any browser.

Nothing is uploaded and nothing runs on a server. The output is one self-contained HTML file — no build step, no dependencies, no account. It is yours, and it works offline.
