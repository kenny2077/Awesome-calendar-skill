Awesome Calendar Skill

The calendar above was generated in one shot from nothing but syllabus files. Here is how to make yours.

Download the skill View on GitHub

  1. Download or copy SKILL.md — one Markdown file, nothing to install.

  2. Paste it into ChatGPT, Claude, Claude Code, Codex — whichever you already use.

  3. Attach your course material: syllabus PDFs, schedule pages, Canvas grade tables, screenshots, plain text. Mixed formats are fine. Messy is fine.

  4. Ask for the semester matrix, then save the HTML it gives you and open it in any browser.

The skill carries a self-inspection loop: the model scores its own render and fixes it before handing it over, which is why the first output is usually the one you keep. Nothing is uploaded and nothing runs on a server — the result is one self-contained HTML file that works offline.
